So the tracker merge is what feeds the phantom loop, and the course-order merge costs gates on top of
it. Both come off the shipping defaults.

Why both passed review and still did this: the tracker fixes were measured by REPLAYING six old
flights, which is open loop - the trajectory is fixed, so a bad target cannot steer the drone
anywhere - and on the rehearsal, whose synthetic detector emits no false positives at all. Neither
harness can close the loop phantom -> target switch -> nose swing -> smeared detection -> phantom.
Only the game can. The rehearsal needs a detector that lies before it can be trusted on this class of
change.
